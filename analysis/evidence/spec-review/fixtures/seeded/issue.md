# Issue 42: Add task search

## Problem
Users cannot find tasks once the list grows beyond a screen.

## Outcome
A user can type a term and see matching tasks.

## In scope
- Title search
- Results for the current user only

## Out of scope
- Full-text search across descriptions
- Saved searches

## Acceptance criteria
- [ ] Searching for a term returns matching tasks
- [ ] A user never sees another user's tasks
