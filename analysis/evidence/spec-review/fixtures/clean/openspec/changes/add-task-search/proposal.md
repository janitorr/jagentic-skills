## Why

Users cannot find tasks once the list grows beyond a screen.

## What Changes

- Add an authenticated title search endpoint scoped to the current user.
- Add a search box in the task list.

## Capabilities

### New Capabilities
- `task-search`: Search the current user's tasks by title.

### Modified Capabilities
None.

## Impact

- Adds a search endpoint, a query, and a UI search box.
